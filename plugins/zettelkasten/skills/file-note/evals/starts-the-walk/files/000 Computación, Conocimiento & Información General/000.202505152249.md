# El usuario de un API es un developer

Un API es un producto y su usuario es un developer. [^1]

Hay que entender quién es, qué necesita y por qué usa el API. Si no, haces APIs que nadie quiere usar.

[^1]: [[Designing Web APIs - Brenda Jin Saurabh Sahni Amir Shevat]]
