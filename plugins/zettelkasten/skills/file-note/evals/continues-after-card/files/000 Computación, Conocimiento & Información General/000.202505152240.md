# Analogía de APIs como piezas de lego

Usar un API es como armar legos: juntas piezas que alguien más diseñó. [^1]

Un buen API es simple y encaja con otros, igual que una pieza de lego.

[^1]: [[Designing Web APIs - Brenda Jin Saurabh Sahni Amir Shevat]]
