# REST vs RPC

REST modela el dominio del negocio con sustantivos (`/users/1234`) y deja la operación al verbo HTTP. RPC expone verbos (`/getUserInfo?id=1234`): cada endpoint es una operación en el servidor.

RPC encaja mejor cuando las acciones no caben en un CRUD o tocan varios tipos de resources.
