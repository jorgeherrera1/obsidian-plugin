# Que es un Agente

Un agente decide por sí mismo cómo hacer una tarea y qué herramientas usar, y cuándo. [^1]

Si el plan de ejecución lo orquesta el código, es un workflow, no un agente.

[^1]: https://www.anthropic.com/engineering/building-effective-agents
